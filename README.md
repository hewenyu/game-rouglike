# game-rouglike

肉鸽小游戏。

当前项目是 [废潮 / SCRAP SURGE](scrap-surge/README.md)：一款网页自动战斗肉鸽，玩家只负责移动，武器会自动开火。一局 20 波，靠武器合成和物品构筑形成连锁正反馈。没有后端，也不依赖外部素材。

```sh
cd scrap-surge
npm ci
npm run dev   # http://127.0.0.1:4188
```
